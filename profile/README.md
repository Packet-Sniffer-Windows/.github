## 🌐 What It Is
Packet Sniffer for Windows is free freeware for capturing and analyzing the network packets on your connection. Pick an adapter, start a capture, and it shows each packet decoded by protocol with clear source and destination details. Filters help you zero in on a single IP or port, and captures save to disk for deeper study. Made for admins, developers, and learners, this network packet sniffer turns raw traffic into something you can actually read.
